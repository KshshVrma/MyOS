# MyOS — Personal AI Assistant

MyOS is a local-first personal AI assistant designed to automate everyday tasks and provide conversational assistance through Telegram.

The initial prototype runs locally with an LLM hosted through Ollama, while n8n handles workflow orchestration and integrations.

## Architecture

```text
Telegram
   |
   v
ngrok (public HTTPS tunnel)
   |
   v
n8n (Docker)
   |
   v
Llama 3.2 3B (Ollama)
   |
   v
Intent detection and validation
   |
   +---- CREATE_REMINDER --> Google Calendar
   |
   +---- CREATE_TASK ------> Planned
   |
   +---- ASK_QUESTION -----> LLM response
   |
   +---- GENERAL_CHAT -----> LLM response
```

## Tech stack

- **Workflow orchestration:** n8n Community Edition
- **LLM runtime:** Ollama
- **Model:** Llama 3.2 3B
- **Containerization:** Docker Desktop
- **Messaging interface:** Telegram Bot API
- **Calendar integration:** Google Calendar API
- **Tunneling:** ngrok
- **Custom logic:** JavaScript

## Local setup

### Prerequisites

- Docker Desktop
- Ollama
- ngrok
- Telegram bot token
- Google Calendar OAuth credentials

### Start Ollama

```bash
ollama pull llama3.2:3b
ollama run llama3.2:3b
```

### Start n8n

```bash
docker compose up -d
```

Open n8n at <http://localhost:5678>.

### Expose n8n for Telegram webhooks

```bash
ngrok http 5678
```

Configure n8n's webhook URL with the HTTPS URL generated by ngrok.

## Project goals

MyOS aims to evolve into a personal productivity assistant capable of:

- Managing reminders and tasks
- Interacting with Google Calendar and Gmail
- Providing daily briefings
- Tracking learning and career goals
- Understanding natural language commands

**Current focus:** Building a reliable local-first assistant before adding persistent storage and integrations, then eventually deploying to a VPS.
